4 사용

어드민 CS > CS 문의 에서 목록이 다 뜬 뒤 북마크를 클릭하세요.

화면 상단에 시트 반영 완료 · ○○행 알림이 뜨면 성공입니다.

중요 — 시트는 보낸 내용으로 통째로 교체됩니다. 목록 아래 Load More 로 필요한 만큼 다 불러온 뒤에 누르세요. 행수가 크게 줄어들면 한 번 되묻습니다.
잘 안 될 때

북마크 우클릭 → 수정 → URL 칸이 javascript: 로 시작하는지 확인하세요.

https:// 로 시작하면 잘못 들어간 것이니, 지우고 위에서 다시 드래그하시면 됩니다.
